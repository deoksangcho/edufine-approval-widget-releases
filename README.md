# 행정실 결재 위젯 다운로드

나이스 미결·협조함, 에듀파인 결재, 교데통 승인 대기, e교육금고 전송대상 건수를 보여 주는 Windows 위젯입니다. Chrome 또는 Edge 확장 프로그램과 연결해 현재 로그인된 업무 사이트에서 조회합니다.

이 저장소는 설치 파일과 사용 안내를 배포하는 공간입니다.

## 다운로드

- [최신 버전 다운로드](https://github.com/deoksangcho/edufine-approval-widget-releases/releases/latest)
- [v0.8.9 Windows 설치 ZIP](https://github.com/deoksangcho/edufine-approval-widget-releases/releases/download/v0.8.9/edufine-approval-widget-v0.8.9.zip)
- [노션 사용설명서](https://dscho.notion.site/edu-approval)

릴리스의 Assets에서 **edufine-approval-widget-v0.8.9.zip**을 선택합니다. `Source code (zip)`에는 설치 프로그램이 없습니다.

## 0.8.9 변경 사항

- 설치 프로그램이 PowerShell 스크립트 없이 설치하도록 바꿨습니다. 백신 프로그램이 설치 과정을 악성 동작으로 오인할 수 있던 방식을 정리했습니다.
- 설치 전용 **Setup.exe**가 파일 복사와 Chrome·Edge 연결 등록을 직접 처리합니다. 관리자 권한은 필요하지 않습니다.
- 압축 폴더에서 `install.ps1`·`uninstall.ps1`·`Install.cmd`가 빠졌습니다. **Setup.exe만 실행**하면 됩니다.
- 실행 파일에 제품명·게시자·버전 정보를 넣었습니다.
- 설치 후 **Windows 설정 → 앱 → 설치된 앱**에서 제거할 수 있습니다.
- 위젯 기능과 조회 방식은 0.8.8과 같으며, 연결 확장은 0.8.8을 그대로 사용합니다. 0.8.8의 설치 후 자동 연결 개선도 유지됩니다.

## 설치

1. ZIP을 모두 압축 해제하고 `Setup.exe`를 실행합니다.
2. 안내창에서 업무용 Chrome 또는 Edge를 선택합니다.
3. 안내에 따라 확장 관리 화면에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**를 선택합니다.
4. 안내창에서 복사한 설치 폴더를 불러옵니다.
5. 연결되면 설치 안내창이 자동으로 닫히고 위젯 설정창이 열립니다. 이 단계에는 업무포털 로그인이 필요하지 않습니다.
6. 설정을 확인한 뒤 같은 브라우저·프로필에서 업무포털에 로그인합니다. 조회가 성공하면 위젯에 건수가 표시됩니다.

기존 사용자는 **새 ZIP의 Setup.exe를 실행**합니다. 0.8.8을 쓰고 있었다면 확장 새로고침은 필요하지 않습니다. 0.8.7 이하에서 올라왔다면 사용하는 브라우저마다 확장 카드의 새로고침(↻)을 한 번 눌러 확장을 0.8.8로 갱신합니다. 브라우저 자동 시작이 켜져 있으면 별도의 ‘위젯 열기’ 없이 자동 연결됩니다. 자동 시작을 꺼 둔 경우에는 기존처럼 수동으로 열 수 있습니다.

종료 후 연결 도움으로 위젯만 다시 열었다면 자동 확인 주기 때문에 약 1분, 절전·브라우저 상태에 따라 더 기다릴 수 있습니다. 확장 등록·새로고침 또는 로그인 감지 시에는 바로 연결을 시도합니다. 상세 안내는 노션과 ZIP 안의 `사용방법.md`에 있습니다. 관리되는 학교 PC의 확장 설치 제한은 해당 기관의 정책을 따릅니다.

## 제거

1. Windows **설정 → 앱 → 설치된 앱**(Windows 10은 **앱 및 기능**)에서 **행정실 결재 위젯**을 찾아 **제거**를 누릅니다.
2. Windows 확인 창에서 한 번 더 **제거**를 누르고, **행정실 결재 위젯을 제거할까요?** 창에서 **예**를 누릅니다. 위젯과 브라우저 연결 등록, 설치 폴더를 지우며 사용량 측정 기록은 남겨 둡니다.
3. 사용하는 Chrome·Edge의 확장 관리 화면에서 **행정실 결재 위젯** 확장도 제거합니다.

설치된 앱 목록에 없다면 0.8.8 이하 방식으로 설치된 상태입니다. 새 ZIP의 `Setup.exe`로 한 번 업데이트한 뒤 제거합니다.

## 백신이 다운로드나 설치를 차단하는 경우

0.8.9는 설치 과정에서 PowerShell 스크립트를 실행하지 않습니다. 2026-09-18 검증 PC의 Microsoft Defender(보안 인텔리전스 **1.459.258.0**)에서 **v0.8.9 설치 ZIP 탐지 0건**을 확인했습니다. 보안 예외 등록이나 실시간 보호 해제는 하지 않았습니다. V3 등 다른 백신의 결과는 확인하지 않았으며, 검사 결과는 검증한 환경의 결과로서 모든 PC에서 같음을 보장하지 않습니다.

Windows 보안을 사용한다면 **Windows 보안 → 바이러스 및 위협 방지 → 바이러스 및 위협 방지 업데이트(보호 업데이트) → 업데이트 확인** 후 다시 다운로드해 주세요.

실행 파일은 코드 서명되지 않아 게시자나 SmartScreen 경고가 별도로 나올 수 있습니다. 탐지가 계속되면 백신을 끄거나 예외로 등록하기보다 백신 종류, 탐지명, 릴리스 버전을 알려 주세요.
